东方古韵 · 山水楼阁
====================

作者说明
本项目由当前 Codex 助手直接编写。没有调用 Gemini、OpenCode Go 或其他推理 API。
所有建筑和植被由代码生成，无付费模型、外部贴图或图片背景。

启动（推荐：完全离线）
1. 安装 Python 3.9 或更高版本。
2. 在本目录打开终端，运行：
   python start.py
3. 脚本自动选择空闲端口，并打开默认浏览器。
4. 关闭服务：在终端按 Ctrl+C。

也可用 VS Code Live Server 或任意静态 HTTP 服务打开 index.html。
不要直接双击离线版 index.html：浏览器通常会阻止 file:// 下的本地 ES 模块。
首次加载不需要联网，Three.js 及官方扩展已随项目附带。

目录内的 single.html（另附同内容“shanshui-courtyard-single.html”）为单文件版：业务代码、样式均内嵌，
Three.js 和官方扩展从 jsDelivr CDN 加载，因此需要联网。

操作
- 默认进入第三人称“小女孩阿棠”漫游：WASD / 方向键移动，Shift 慢跑。
- 拖动鼠标调整跟随视角，滚轮调整跟随距离；手机用屏幕方向按钮移动。
- 面向主楼，走前方台阶和已打开的门进入一层；室内右侧木梯通往二楼。
- 室内镜头自动避让墙体，狭窄处角色淡化；池水有边界，可从石桥跨过。
- “少女漫游”切换角色控制和建筑总览；点击正面或鸟瞰会退出漫游。
- 漫游中“重置”让女孩回到入口道路；总览中“重置”恢复建筑视角。

建筑总览操作
- 鼠标左键拖动：环绕观察。
- 滚轮：缩放；右键拖动：平移。
- 白昼 / 黄昏 / 夜景：切换天空、环境光、太阳/月光、窗纸和灯笼。
- 正面 / 鸟瞰 / 重置：切换或恢复相机。
- 点击建筑：显示屋顶、斗拱、梁柱、格栅、池桥或回廊的说明。
- “构件导览”：用按钮直接选择结构说明。
- 手机：单指旋转，双指缩放和平移。

实现说明
- 两层楼阁：立柱、石础、梁枋、层叠斗拱、立体格栅和栏杆。
- 歇山顶：参数化曲面、翘角、山面三角山花、脊线和鸱吻意象。
- 5,862 片筒瓦：薄壁半圆筒几何，沿坡面切线逐行排布和搭接。
- 重复木构、石构和植被合并为 InstancedMesh，减少 Draw Calls。
- 水面使用实时平面反射，并对反射采样做时间相关的波纹扰动。
- 木纹和石材纹理由 Canvas 程序生成，PBR 材质、ACES 色调映射、阴影和雾。
- 斗拱采用传统层叠构造的程序化表达，并非某一具体古建筑的测绘复原。

角色和室内
小女孩为程序化制作的古风卡通角色，带发髻、衣裙、行走摆臂和双腿动画。
一层设会客桌椅、茶具和书架，二层设茶桌；两层之间有实体木梯及楼板开口。
移动使用针对庭院的轻量运动学碰撞，不包含跳跃、战斗或完整刚体物理。

边界
需要支持 WebGL 2 的浏览器和显卡；低性能设备可调低 scene.js 中的像素比、
反射贴图分辨率或阴影尺寸。阴影和反射属于实时近似，不是离线路径追踪。
本项目不包含任何模型 API Key、联网聊天或计费调用。
